# Slack Alarm

原生 macOS 菜单栏 Slack 闹铃。完全在本机运行，不使用 Slack API、token、服务器或网络请求。

**公开测试版：v1.1.2-beta.1 · 仅 Apple Silicon · MIT 许可**

此版本只有临时签名，没有 Developer ID 签名或 Apple 公证，macOS 可能阻止打开。请从仓库 **Releases** 下载应用 ZIP，而非 Source code。

## 使用

1. 退出旧版，将 应用 ZIP 中的 `Slack Alarm.app` 放到固定的非同步目录，再启动。
2. 打开 **Diagnostics / 诊断**，进入系统设置，为实际运行的应用开启完全磁盘访问权限，然后退出并重开。
3. 在 **Settings / 设置** 每行填写一个名字，点击开启闹铃。无需先检查样本或验证。
4. 测试闹铃；通过闹铃窗口、设置或菜单点击停止。
5. 如需查看通知，点击「查看 / 刷新」，最多显示 3 条样本，含有限长度的正文，仅保留在内存中；可随时清除。

启动默认不开启闹铃。停止当前闹铃后，新消息仍可再次触发；关闭闹铃不自动停止当前正在播放的声音。退出会立即停止音频。修改名字或 @ 规则后需重新开启闹铃；切换语言、调整音量不影响闹铃开关。

## Slack 设置与限制

开启 Slack 桌面通知、私信、@ 提醒和消息预览；确认通知进入 macOS 通知中心。测试时关闭勿扰／专注模式，切到其他对话。Slack 未产生系统通知时无法检测。

名字在标题或副标题中出现即触发，较长名字、频道名或工作区名包含目标文字时也可能触发；无法据此识别 Slack 用户 ID。普通正文提及名字不触发；可选 @ 规则另计，它只匹配实际显示的字面文本，不等于 Slack 的真实提及语义。

系统静音、耳机输出和休眠会影响声音。音量只调整应用自身。防闲置休眠不绕过合盖或主动休眠。通知数据库可能延迟写入或清理，不能保证即时或绝不漏报。

完全磁盘访问权限允许接触其他应用的通知数据，但本程序只解析 Slack，不保存正文、不联网。用户主动查看的样本最多 3 条，标题／副标题各限 160 字符，正文限 300 字符。

## 构建与验证

最低部署 macOS 13，Swift tools 5.9+。本次在 macOS 15.7.7 arm64、Swift 6.2.4 上完成 Debug / Release 构建，**14 项测试通过**。应用打包及 ZIP 解压后签名校验通过。

```bash
./scripts/build.sh
```

项目在同步目录中时，文件提供程序可能重新附加 Finder 元数据，导致签名校验失败。请使用非同步输出目录：

```bash
DIST_ROOT=/private/tmp/SlackAlarm-local ./scripts/build.sh
```

脚本默认临时签名，未做 Developer ID 签名或公证，不能保证下载后无系统提示。升级改名保留原 Bundle ID `local.slackwake.app`，以延续设置；旧模式、发送人确认和快捷键值不再使用。重签名或移动路径可能需要重新授予完全磁盘访问权限。不要同时运行新旧版本。

当前 Computer Use 权限阻止了桌面界面验收，未声称实际图标大小、双语布局、出声、权限撤销和睡眠恢复已验证。此前迁移审查读取真实通知数据库被拒绝，当前机器的真实 Slack 通知端到端验收仍待完成。

人工验收：目标消息响铃 → 停止 → 下一条重新响铃；非目标及仅正文提及不响铃；菜单展开时接收消息；切换语言并重启；撤销／重新授权；睡眠后恢复。可选 @ 提醒单独测试。

通知读取、只读 SQLite/WAL、去重和重建处理、构建选项及源码布局详见 [英文 README](README.md)。将本目录作为 GitHub 仓库根目录即可；缓存与 `dist/` 已列入 `.gitignore`。
